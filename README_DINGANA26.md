# Battle Royale — Dingana 26

Android wrapper project for the existing Battle Royale web UI.

## What is included
- Android Gradle project
- Portrait phone layout
- Local WebView loading `index.html`
- JavaScript + local storage enabled
- Application name: Battle Royale

## Important
This is an Android **source/build project**, not a prebuilt APK. A real APK requires an Android SDK/Gradle build environment. The current source UI is the existing prototype UI; native multiplayer, ads, and production server are separate integrations and are not magically created by this wrapper.
